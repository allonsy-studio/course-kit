<practice-terms>

A bank of terms, each opening its definition in a popover.

Practice worksheets

Examples

Default

Source 
<practice-terms :@terms="([{&quot;term&quot;:&quot;landmark&quot;,&quot;definition&quot;:&quot;A page region with a role and a name, such as `header` or `nav`.&quot;,&quot;source&quot;:{&quot;label&quot;:&quot;Week 1 slide 2&quot;,&quot;week&quot;:1,&quot;day&quot;:1,&quot;slide&quot;:2,&quot;href&quot;:&quot;/slides/week-1-day-1/#s2&quot;},&quot;id&quot;:&quot;term-1&quot;}])" @hint="Select a term for its definition."></practice-terms>

Props

Write them with the @ prefix, and :@ for an expression. A prop in square brackets is optional.

Name Type Description
terms { id: string, term: string, definition: string, source?: object }[] the terms, each with its definition
[hint] string a line above the bank
[sourceprefix] string text before each source link's label

Color tokens

The tokens this component's styles read. Set one in _data/theme.json to change it everywhere.

Type a value to try it in every example above.

Token Colors Try a value
--color-accent Brand color: fills, buttons, rules, the masthead wash
--color-border Lines, rules and borders
--color-surface Raised or alternate surface: cards, table headers, code
--color-surface-overlay Popovers and menus
--color-text Body text
--color-text-muted Secondary text
