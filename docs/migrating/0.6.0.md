# Migrating to 0.6.0

Notes for 0.6.0. The changelog entry links here. It is a minor release because it removes copy keys; a course that does not override them keeps building with no change.

## The home band has two panels

`<course-now>` shows the **next class** and **Coming up**, then the progress track. The This week panel from 0.5.0 is gone: whenever the next class opened the week, over every weekend and break, it repeated the card.

- The Next class card's one link is **See the week**, to that class's week on the schedule (`/schedule/#week-<n>`, built from `scheduleUrl` so a path prefix is kept).
- **Open the slides** is gone from the card. The slides are linked from the schedule's week and from the menu.
- A course that overrides `course-now.webc` re-merges its copy: `[data-this-week]` and `[data-now-slides]` are gone, `[data-now-week]` is new, and the band's JSON no longer carries `weeks` or each meeting's `slides`.

## Removed copy keys

`home.openSlides`, `home.weekThis`, `home.weekNext`, `home.weekFirst`, `home.weekWhen` and `home.weekWhenDay`.

- Delete any of them from `strings.json`, or the build fails with `strings.json: "home.weekThis" is not a copy key`.
- `home.seeWeek` ("See the week") stays.
