<glossary-panel>

The glossary's element: the plain list it wraps (the slot) stays when scripts do not run, and scripts/glossary.js replaces it with Review and Flashcards. One stylesheet covers both, since the script renders the same markup the server does.

Color tokens

The tokens this component's styles read. Set one in _data/theme.json to change it everywhere.

Type a value to try it in every example above.

Token Colors Try a value
--color-accent Brand color: fills, buttons, rules, the masthead wash
--color-accent-text Brand color for type, dark enough to read
--color-border Lines, rules and borders
--color-page Page background
--color-success Success: correct answers, confirmations
--color-surface Raised or alternate surface: cards, table headers, code
--color-surface-accent Accent-tinted wash
--color-tag-meeting Glossary tag hue for class meetings; its tints derive from it
