CS101: Introduction to Web Publishing

An introduction to publishing on the web: writing pages in HTML, styling them with CSS, and putting them online.

Prerequisites: None

How this section is taught

Every class mixes a short talk with time to build. You learn by making a small site that grows all term.

Syllabus

Learning outcomes

Upon completing this course students will be able to:

  • Write well-structured HTML pages.
  • Style a page with CSS so it works on a phone and a laptop.
  • Publish a small site and keep it up to date.
