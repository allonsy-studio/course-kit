<codepen-embed>

A live code sample: a header with actions, then the CodePen embed prefilled with the code.

Building blocks

Examples

Default

Source 
<codepen-embed @heading="A first page" @label="A first page in HTML" @summary="Open the pen and change the heading." :@height="300">
	<template slot="actions" webc:nokeep><a href="https://codepen.io/">Open in CodePen</a></template>
	<p>The embed loads when you click.</p>
</codepen-embed>

Props

Write them with the @ prefix, and :@ for an expression. A prop in square brackets is optional.

Name Type Description
[heading] string the header, default "The code"
label string the pen's title
summary string the pen's description
[height] number embed height in pixels, default 800
[tags] string[] tags added to the pen

Slots

Name Description
actions buttons beside the header
default extra content under the code

Color tokens

The tokens this component's styles read. Set one in _data/theme.json to change it everywhere.

Type a value to try it in every example above.

Token Colors Try a value
--color-accent Brand color: fills, buttons, rules, the masthead wash
--color-border Lines, rules and borders
--color-page Page background
--color-text-muted Secondary text
