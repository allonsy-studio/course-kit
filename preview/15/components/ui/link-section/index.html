<link-section>

A titled list of links. Renders nothing when there are no items and no empty text.

Building blocks

Examples

Default

Source 
<link-section @title="Read before class" :@items="([{&quot;title&quot;:&quot;MDN: How the web works&quot;,&quot;href&quot;:&quot;https://developer.mozilla.org/docs/Learn_web_development/Getting_started/Web_standards/How_the_Web_works&quot;},{&quot;title&quot;:&quot;Chapter 1&quot;,&quot;note&quot;:&quot;pages 1–20&quot;},{&quot;title&quot;:&quot;The HTML spec&quot;,&quot;href&quot;:&quot;https://html.spec.whatwg.org/&quot;,&quot;extra&quot;:{&quot;text&quot;:&quot;section 4&quot;,&quot;href&quot;:&quot;https://html.spec.whatwg.org/#semantics&quot;,&quot;after&quot;:&quot;(skim)&quot;}}])"></link-section>

Empty

Source 
<link-section @empty="Nothing to read this week." :@items="([])"></link-section>

Props

Write them with the @ prefix, and :@ for an expression. A prop in square brackets is optional.

Name Type Description
[title] string the heading; left out when there are no items
items { title: string, href?: string, note?: string, extra?: { text: string, href: string, after?: string } }[] the links to list; an item with no href is plain text
[empty] string shown, muted, when there are no items
