<week-block>

One bordered block per week: a tinted header band, then the slot.

Building blocks

Examples

Default

Source 
<week-block :@number="3" @dates="Sep 14 – Sep 18"><p>The week's meetings go here.</p></week-block>

Props

Write them with the @ prefix, and :@ for an expression. A prop in square brackets is optional.

Name Type Description
number number the week number (not week: slot content sees a component's props, and a host loops over week)
dates string the week's date range, shown beside the heading
[level=3] 2 | 3 the heading level

Color tokens

The tokens this component's styles read. Set one in _data/theme.json to change it everywhere.

Pick a color to try it in every example above.

Token Colors Try a color
--color-accent Brand color: fills, buttons, rules, the masthead wash
--color-border Lines, rules and borders
--color-surface Raised or alternate surface: cards, table headers, code
--color-text-muted Secondary text
