<choice-list>

A radio group of lettered choices.

Practice worksheets

Examples

Default

Source 
<choice-list @legend="Choose one answer" :@choices="([{&quot;name&quot;:&quot;q&quot;,&quot;value&quot;:&quot;0&quot;,&quot;text&quot;:&quot;A list of links&quot;,&quot;letter&quot;:&quot;a&quot;},{&quot;name&quot;:&quot;q&quot;,&quot;value&quot;:&quot;1&quot;,&quot;text&quot;:&quot;The page's footer&quot;,&quot;letter&quot;:&quot;b&quot;}])"></choice-list>

Props

Write them with the @ prefix, and :@ for an expression. A prop in square brackets is optional.

Name Type Description
choices { name: string, value: string, text: string, letter?: string }[] the options, one radio button each
[legend] string the group's legend
[legendclass] string class for the legend, such as sr-only

Color tokens

The tokens this component's styles read. Set one in _data/theme.json to change it everywhere.

Type a value to try it in every example above.

Token Colors Try a value
--color-accent-hover Brand fill, hovered
--color-error Error: wrong answers, failures
--color-on-error Text on an error fill
--color-on-success Text on a success fill
--color-success Success: correct answers, confirmations
--color-surface Raised or alternate surface: cards, table headers, code
