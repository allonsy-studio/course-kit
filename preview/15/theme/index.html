Theme

Every color token, what it colors, and a light and a dark color picker to try one. A color applies to every example on every page, and is kept in this browser until you reset it. The defaults are in docs/tokens.md.

Token Colors Try a color
--color-page Page background
--color-surface Raised or alternate surface: cards, table headers, code
--color-surface-subtle Faint surface tint
--color-surface-overlay Popovers and menus
--color-surface-accent Accent-tinted wash
--color-table-header Table header cells
--color-surface-warning Warning panel background Decks only
--color-text Body text
--color-text-muted Secondary text
--color-border Lines, rules and borders
--color-border-accent Accent-tinted line Decks only
--color-accent Brand color: fills, buttons, rules, the masthead wash
--color-accent-text Brand color for type, dark enough to read
--color-accent-strong Brand color for decorative marks: the text tone in light mode, the fill in dark Decks only
--color-on-accent Text on a brand-color fill
--color-accent-hover Brand fill, hovered
--color-accent-active Brand fill, pressed
--color-link Links
--color-link-hover Links, hovered
--color-link-focus Links, focused
--color-link-active Links, pressed
--color-success Success: correct answers, confirmations
--color-on-success Text on a success fill
--color-error Error: wrong answers, failures
--color-on-error Text on an error fill
--color-warning Warnings and cautions
--color-on-warning Text on a warning fill
--color-highlight Highlighted (marked) text
--color-tag-test Glossary tag hue for tests; its tints derive from it
--color-tag-reading Glossary tag hue for readings; its tints derive from it
--color-tag-meeting Glossary tag hue for class meetings; its tints derive from it
--color-code Preformatted code text and its border
